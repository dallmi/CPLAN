# Key messages

Three messages, never more. A speaker on stage retrieves at most three
things under pressure; a brief with five key messages has decided nothing
and delegated the cut to the worst possible moment.

## The shape of one message

Each message is three lines:

- **The message** — one declarative sentence a speaker can say verbatim.
  If it cannot be said aloud in one breath, it is not a message yet.
- **The proof** — one fact or example from the source material that makes
  the sentence credible, with its source named.
- **The bridge** — the phrase that returns to this message from an
  unrelated question ("What I'd point to is…").

## Disqualifiers

A draft message is rejected — not softened, rejected — when it:

- cannot cite a proof line from the sources in §10 of the brief. A message
  without evidence is a slogan, and slogans are what Q&A punishes;
- contains a superlative or a claim of leadership ("best", "leading",
  "unique") — these are the first thing a journalist or analyst tests;
- contains a number that does not appear verbatim in a source. Numbers are
  never derived, rounded or updated by the drafting agent;
- makes a forward-looking statement with a date or figure attached, unless
  the source is an already-published external statement. Anything else is a
  disclosure question and goes to the owner, not into the brief;
- needs a subordinate clause to be true. A message that is only true with
  a caveat gets the caveat said on stage or gets cut.

## Derivation

Draft from, in this order of authority: the stated objective of the
engagement (§2 of the brief), the source documents supplied for this
engagement, the context pack's record of what was said to this audience
before. Where the sources conflict, say so to the reviewer instead of
choosing silently. Where the objective is missing, no key messages are
drafted — the gap is the finding.

Messages must not contradict what the context pack shows was said to the
same audience in the recent window. If a tension exists (the story has
changed), the message is still draftable but the tension is named in a
reviewer note beside it — the speaker must not learn about it from the
audience.

## Review marker

The section carries `Draft — not yet reviewed` until a named reviewer
removes it. The drafting agent never removes the marker itself.
